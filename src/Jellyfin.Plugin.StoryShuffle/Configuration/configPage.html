Story Shuffle

Takes over the normal Shuffle button on series and seasons so multi-part stories always play complete and in order.

Some TV and third-party apps ask for "random episodes" in a different way. Turn off if one of them misbehaves.

Defaults for every series

Your series rules

A JSON list. Each rule matches series by name (a year like "(2005)" is ignored) or Jellyfin id, and adds to the built-in rules. Episodes can be given by title or as S06E01. Every field except series is optional. 
[
  {
    "series": ["Star Trek: The Next Generation"],
    "groups": [ ["The Best of Both Worlds (1)", "The Best of Both Worlds (2)"], ["S06E10", "S06E11"] ],
    "seasonsAsStory": [],          // seasons that play start to finish as one story
    "neverGroup": [],              // titles the automatic linking must leave alone
    "exclude": [],                 // titles never queued
    "titleHeuristic": true, "overviewHeuristic": true, "excludeSpecials": false,
    "enabled": true,               // false = normal shuffle for this series
    "replaceBuiltIn": false        // true = ignore the built-in list for this series
  },
  { "series": ["South Park"], "seasonsAsStory": [20] }
]
